# 🥤 Düşünen Çaydanlık Simülatörü

## Resmi Açıklama

Bu repository, insanlık tarihinin en büyük felsefi problemine çözüm getirmek amacıyla yaratılmıştır: **Bir çaydanlık düşünebilir mi?**

Cevap: Evet. Ve sen de dinlemelisin.

### Özellikler

- Gerçek zamanlı düşünme (yaklaşık 10 saniye sürer, çünkü derin düşünceler acele etmez)
- Rastgele Türkçe felsefi çay yorumları
- Kaynama sesi simülasyonu (print ile)
- Evreni sorgulama garantisi

### Nasıl Kullanılır

```bash
python3 caydanlik.py
```

Sonra çayını al, otur, ve çaydanlığın söylediklerini ciddiye al. Ya da alma. Çaydanlık umursamaz.

### Uyarı

Bu yazılım aşırı düşünce üretebilir. Sorumluluk size aittir. Çay içmeyi unutmayın.

### Geliştirici Notu

Bu proje, çay içerken aklıma geldi. Sonra çay bitti, proje bitmedi. Klasik.
